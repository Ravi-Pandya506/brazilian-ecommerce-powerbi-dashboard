# Brazilian E-Commerce Power BI Dashboard

## Project Overview
This project analyzes Brazilian e-commerce data using PostgreSQL and Power BI.

The dashboard provides insights into:
- Sales performance
- Customer behavior
- Product categories
- Delivery performance
- Seller analysis
- Payment trends
- Customer reviews

---

## Dataset
Brazilian E-Commerce Public Dataset by Olist

Dataset Link:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce/data

---

## Tools & Technologies
- PostgreSQL
- SQL
- Power BI
- DAX
- Power Query
